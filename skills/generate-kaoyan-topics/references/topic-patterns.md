# 选题机制与正文要求

这些是创作和验收框架，不是经过统计验证的流量公式。胡跳跳样本支持的实际观察见 [creator-samples.md](creator-samples.md)。

## 六种可迁移机制

| 机制 | 用户真正要解决的问题 | 标题的组织方式 | 正文至少交付 |
|---|---|---|---|
| 决策风险识别 | 我怕把时间投入到不适合自己的目标 | 具体身份/阶段 + 某个选择 + 要核实的条件 | 有来源的判断维度、适用范围、演示和行动清单 |
| 条件对比 | 选项很多，我不知道哪种适合当前的我 | 当前状态 + 两类选项 + 选择问题 | 比较标准、各自适用条件、实例和下一步 |
| 分阶段执行 | 有目标，但不知道今天先做哪一件事 | 阶段 + 本周/本次任务 + 完成标准 | 顺序、可用时间、具体任务、检查与调整办法 |
| 场景解卡 | 已经走到某一步，但不知道下一句话/下一动作 | 一个真实场景 + 卡住的位置 | 错误或不充分示例、改进示例、可直接执行的步骤 |
| 操作演示 | 知道该查或该做，但不知道入口和过程 | 要完成的操作 + 明确输出 | 可观察的步骤、实际页面/材料、结果解释与常见例外 |
| 动机与判断 | 对考研有摇摆，想知道投入对自己有什么意义 | 具体疑问或两难 + 一条可讨论的观点 | 理由、适用情况、反例和自问清单；避免只做情绪口号 |

## 从参考变成原创

依次变换目标人群、眼前任务、具体素材和讲述形式。保留的是“怎样帮观众解决一个问题”，不是只替换原标题里的几个词。

### 例一：从院校判定转向可核查的方法

参考结构：身份筛选 → 学校清单 → 每所的简短理由。

可以迁移的原创选题：**“双非第一次择校，先把这三类公开信息查清楚。”**

可交付：用一所真实目标院校作演示，区分招生目录、报考要求与复试办法各自回答的问题，填写一张信息对照表。发布前检查该年度文件；文件尚未公布时明确历史参考。

不合格版本：只更换五所学校，并写“学姐带你避雷”；没有院系和年份，靠评论传闻下结论。

### 例二：从资料书清单转向选择规则

参考结构：模块拆分 → 选项 → 适合的基础/用途 → 如何使用。

可以迁移的原创选题：**“两本考研英语真题书怎么选？先翻这三处再决定。”**

可交付：选取当前真实可取得的样张，对比原文与解析的对应方式、难句说明、做题复盘空间，并解释这些差别怎样影响不同基础考生使用。具体版本、价格与购买建议另行核实；未取得样张就标为待准备，不能虚构评测。

不合格版本：抄一份多年以前的书单，冠以“今年必买”，或者用无依据分数段指定唯一老师。

### 例三：从时间节点转向完成一次任务

参考结构：阶段提醒 → 关键事项 → 具体动作。

可以迁移的原创选题：**“每天只有两小时备考，周计划怎么排才知道自己做没做完？”**

可交付：明确这只是示例安排；把“学英语”拆成有材料、有动作、有完成标准的一项任务，再演示如何在一周后调整。不要把同一时间表承诺适合所有人。

不合格版本：把未公布的报名、确认日期当成确定时间，或者给所有考生同一份精确计划。

### 例四：从泛泛沟通转向实际场景

可以生成：**“加上目标院校学长学姐后，第一条消息怎么发？”**

可交付：将缺少背景的提问改成包含报考年份、目标专业、已查信息和一个明确问题的消息；提醒对方经历只代表对应年份与专业。给一个完整示例，而不只说“礼貌一点”。

## 展开卡片模板

按需要合并字段，避免空模板占据用户答案。

**题目：** 一个承诺，明确人群或情境。

**为什么先做：** 与用户能力、当前受众需求或可用材料的具体关系。

**痛点与钩子：** 用户眼前卡在哪里、可能担心什么；开头用什么具体信息让其继续看。没有访谈或评论依据时，将深层动机表述为创作假设。

**开头：** 直接让观众认出自己的问题，随后说明本条会交付什么。

**正文三段：**

1. 用可观察的情境或例子把问题说清楚。
2. 展示判断方法、对比条件或操作过程。
3. 让观众完成一次选择/填写/自查，并说明何时需要调整。

**展示材料：** 真实网页、获准使用的记录、自己制作的表格或清楚标为假设的示例。

**核查项：** 哪一条事实需要什么年份、哪个单位的来源；已有来源给链接。

**可选结尾：** 同一问题的一步行动。没有真实资料包就不写“已经整理好，私信领取”。

**兑现检查：** 观众看完后具体能完成什么；标题里的数字、比较和承诺是否逐一对应。

## 准备程度

- **可先制作**：主要依靠用户能完成的演示或明确标注的示例，不依赖尚未取得的关键事实。
- **补材料后制作**：需要真实样张、当年文件、用户案例授权或可验证数据，明确列出缺什么。
- **暂不适合**：关键判断超出创作者当前能力或缺少无法替代的证据；直接给一个更合适的替代选题。

这三个等级表示制作条件，不表示预期播放量。新手也可以做信息查询型内容，但必须查对、讲清来源，不能把公开整理包装成多年辅导经验。
