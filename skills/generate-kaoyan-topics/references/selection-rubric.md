# 选题判断标准清单

每次生成选题，用这张表先筛候选，再排优先级。标题和开头在正文交付成立后定。

## 研究标准

- 近期 IP 研究先检查近 30 天。同账号可比视频较少时扩至近 90 天，分别记录窗口、观察日期和覆盖数。作者作品、置顶旧作、图文和推荐视频按实际身份、形式和日期识别。按用户指定范围调整。
- 同时看点赞和评论的绝对量，各自排序后取靠前的作品。两榜重合的优先细拆。收藏和分享可用于看哪些材料值得回查。播放未知时用公开累计数，说明上线时长和曝光未知。
- 留一至两条同人群、同任务但互动较低的对照。发布时间、形式和长度能接近就优先接近。再看开头画面、正文兑现和末尾，标注每条实际看到的范围。
- 把高评论作品中的具体问题作为待验证需求。同样记录质疑、纠错和争议，选题是否值得做由问题和正文证据决定。

## 入选检查

| 必须过的检查 | 判断方法 | 没过怎么处理 |
|---|---|---|
| 人群与情境 | 一句话能说清是谁、准备到哪一步、卡在哪个动作 | 缩到一个阶段和一个动作 |
| 正文结果 | 看完能填表、划掉候选、判断条件、找到入口或改一条提问 | 先确定一个可见结果 |
| 证据与范围 | 具体事实有原件或明确核查路径，年份、院系、专业与统计口径对得上 | 先做查询演示或换掉缺证据的结论 |
| 创作者做得到 | 用能取得的原件、实录、示例表或经验完成，交付与实际资历一致 | 改成可实拍的一步，或放入待准备池 |
| 标题开头与正文一致 | 把首句和正文最后一个实际交付连起来读，数量、条件与结论对得上 | 缩窄承诺，再润色开头 |
| 有原创增量 | 相对参考片增加了新的判断条件、可复用材料或实操步骤 | 合并换词重复题，重做正文 |

## 通过后怎么排序

1. **先拍**：贴合眼下任务，素材已可取得，有一个镜头能展示结果，且能解释为什么优先。默认给出前三条。
2. **备选**：问题成立且有价值，等一份原件、一个可展示的实例或一个节点。明确写待补材料或适合什么时候发。
3. **探索**：有自己的判断依据，尚未看到同类互动信号，保留一个可验证假设。优先测试一种开头，把正文和受众保持一致。

优先级结合本批目标。想扩大相关触达，优先选受众能立即认出的决策困难。想积累信任，优先选观众能亲手完成的核对。既往数据提供研究方向，制作能力和正文兑现决定能否进入选题表。
