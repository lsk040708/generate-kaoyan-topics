# 考研选题生成器

按「有数据的作品 → 自己的判断 → 人群需求 → 传播方法 → 原创选题」的顺序工作。生成的核心单位是「一个具体考生问题 + 一个吸引注意的入口 + 一份正文确实能交付的帮助」。用简体中文和普通人听得懂的语言输出，除非用户另有要求。

使用前先读 [研究判断、人群理论与传播方法](references/creative-methodology.md)。这是本技能的核心方法，不要跳过研究判断直接套标题公式。用户只要短结果时可压缩展示，但仍完成内部分析。

## 1. 确定任务和创作者条件

按用户意图选择一种或多种任务：

- **生成**：给出原创选题池，展开最适合先做的选题。
- **拆解**：把参考作品的标题承诺与实际内容逐项对应，再迁移结构。
- **检查**：找出已有选题、脚本的承诺缺口，直接改成能兑现的版本。
- **复盘**：利用用户提供的同账号表现数据更新下一批选题，不把相关性写成因果。

优先从当前对话提取：发布平台、目标考生及阶段、创作者经历与可用材料、希望获得的结果、已存在且能交付的产品、数量和内容形式。保留用户已经确认的选择。

信息不足时先做有用的工作，不进行长问卷。默认：抖音；刚进入赛道的创作者；面向准备启动备考的本科生；没有可宣称的上岸成绩、辅导案例或已完成的资料包；尚未确定付费产品；以实用内容建立信任。用一句话说明实际采用的假设。

只有缺失信息会改变结论或使内容无法成立时，才集中问一至两个具体问题；同时交付不依赖该信息的部分。例如，院校推荐必须知道目标专业与报考背景，普通信息查询教程可先生成。

不要从“考研赛道”自行推定学科、学校、考试年份或用户的教学资历。用户明确说“28考研”等目标时沿用；涉及实际日程时核实官方年份和日期，不把日历年份自动等同于招生年份。

## 2. 先建立证据，再拆解参考作品

首次使用内置案例、或任务包含参考博主拆解时，读 [参考作品与证据边界](references/creator-samples.md)。需要交付设计和例子时，读 [选题机制与正文要求](references/topic-patterns.md)。用户未指定新博主时，用内置高互动样本作为历史研究基础；要求近期热点、当前表现或新博主时再更新数据。不为了生成通用选题重复抓取全部旧视频。

有新参考链接时，优先读取原作、主页与实际正文，并验证作品确属该作者。记录观察时间、原作链接、发布年份、时长、指标名称与原值。账号累计数据、合集播放与单条数据分别记录。

 用户指定届次和当前任务时，优先补充至少一条贴近该人群的作品。可以用跨平台样本拓展创作思路，比较时保留平台、视频形式和观察日期。有公开作品数据时记录点赞、收藏、评论等实际字段，按证据范围判断；只有标题或简介时，分析其承诺和表达，并注明正文核验范围。

按实际取得的材料标注内容来源，不强行升级：

| 取得的材料 | 可做的分析 | 不可声称的内容 |
|---|---|---|
| 完整视频或完整字幕并已核对 | 内容顺序、开头、结尾、论据和兑现程度 | 未取得的后台转化或曝光原因 |
| 部分画面或字幕抽帧 | 指定时间段实际出现的内容及覆盖范围 | 已听完整口播、没有出现在抽帧中的内容必然不存在 |
| 平台自动转写或摘要 | 可能的内容结构，注明识别与概括风险 | 原作者准确措辞、精确时间轴、摘要必然完整 |
| 标题、封面或评论 | 人群、痛点、承诺；评论中的需求线索 | 视频正文已兑现、结尾实际引流、评论指控属实 |

无法访问正文时直说一次，照样拆标题并给出“正文需要交付什么”；把“作者实际说了什么”标为待核验。需要进一步逐句拆解时再请用户上传视频或字幕，不编造口播。

热度比较优先采用同账号、相近阶段和形式的多个样本，并加入至少一个较低互动对照。未取得全量作品时称为“抽样中的较高互动作品”。点赞、收藏、评论、分享是不同指标；没有播放量不算播放互动率，没有成交资料不判断收益。避免把少量样本包装成平台算法规律。

每个可分析作品建立以下对应关系：

1. **谁在什么情境下需要它**：身份、阶段与眼前任务。
2. **用户的原话式困惑**：例如“学校名字都听过，但我不知道先排除哪一个”。
3. **标题和开头承诺**：分别记录发布标题与实际开场；不能把两者混为一谈。解释其抓手是信息缺口、决策风险、结果期待、身份认同还是观点冲突，具体到原作而非只贴“反差钩子”等标签。
4. **正文如何兑现**：实际内容顺序、例子、判断依据、画面材料与可执行产出。
5. **还缺什么**：数字清单数量、年份、适用范围、来源、条件与标题夸大的部分。
6. **下一步承接**：仅记录可见的结尾或评论承接，二者分开；不能据此推断已经成交。
7. **可以迁移的结构**：保留需求与组织方式，重写表达并更换证据和案例。

拆完后必须给出自己的判断：该样本对吸引目标观众、建立信任、引出进一步需求分别有何借鉴价值；哪些判断有内容证据，哪些只是待测试解释；对当前创作者应优先学什么、为何。不能以“它赞多，所以照着拍”代替判断。

## 3. 选择人群和传播方法

依据核心方法文件，先写一个人群任务句：「处于什么情境的谁，想完成什么进展，被什么阻碍，希望得到什么可见结果」。同时区分功能需求、可能的情绪顾虑与社会认同；心理层判断没有评论或访谈支持时标为创作假设。

按当前任务和需求阶段细分，不只按“双非、本科生、女生”等身份贴标签。一批选题确定一个主要人群，允许覆盖相邻问题；不要把择校新手、冲刺考生和复试人群无理由混在一批。明确本批偏向扩大相关触达、建立信任还是让已有需求表达出来，承接用户实际业务条件。

每条选题选择一至两项适用的传播技巧：身份/场景确认、信息缺口、可解释的观点冲突、有限清单、结果预览、可视化比较、分段兑现或系列连接。写清其对应的用户顾虑和正文证据，不堆砌“逆袭、必看、99%不知道”等词。

对优先展开的选题，生成两个开头或标题版本，并解释更推荐哪一个。两个版本必须保持同一正文承诺，方便后续验证表达差异；不同时改变人群、题目、时长和交付。将“爆款技巧”称为待测试的创作方法，不能宣称平台算法偏好或必然起量。

## 4. 生成选题，先考虑正文能否完成

围绕用户的受众与当前任务，先在内部形成候选，再去重并择优输出。默认十个选题、展开前三个。用户指定数量、形式或深度时以用户要求为准。

优先组合这些维度：

- **阶段**：要不要考、初步择校、启动复习、推进与复盘、报考流程、复试准备。
- **任务**：查信息、作比较、做计划、判断进度、解决一次具体卡点。
- **困惑**：不懂标准、资料过多、计划不可执行、投入与产出不清、流程有遗漏。
- **交付形式**：查询演示、条件对比、填表示例、前后改写、步骤清单、一次复盘。

一批选题应覆盖数种真实问题与内容形式；不要十个标题都靠风险、逆袭或制造焦虑。保留用户明确要求的专题集中度。标题只保留一个主要承诺，给出人群或场景，并使用可理解的词。

**必须先填好每条的“正文交付物”，再润色标题和开头。** 交付物是观众看完能做出的选择、动作或自查结果，例如“用一张表比较两个专业的公开报考要求”。“干货、认知提升、坚持努力”不能单独算交付物。

为每个优先选题写三个可展开的正文要点，并至少给出一个示例、可展示的材料或操作过程。三个要点不能只是重述标题。清单数量必须与正文一致；比较必须说明比较条件；方法必须有做法和判断是否有效的标准。

对没有经历与案例的新创作者，优先选择公开信息核查、真实学习记录、资料整理过程、操作演示和有边界的对比。不要编造“我当年上岸”“带过几百人”“学员提分”等身份与证据。需要专家判断的题可改成问题清单、查证教程，或说明需要专业审核后才适合发布。

## 5. 约束事实、承诺与商业承接

具体招生条件、考试科目、院校政策、日程、书目版本与当前资源推荐都可能变化。需要这些事实时，查询当年度研招网、招生单位官网及对应学院或专业文件；保留链接、年份和适用范围。缺少来源时写清需要核实的材料，输出查询方法或框架，不能补造数值或推荐名单。

不要用去年的资料推断未来年度政策；区分官方已公布、历史参考和创作假设。内置旧视频只证明曾采用某种内容结构，不证明其中建议现在仍有效。

 面向尚未定校的考生，先用官方硕士专业目录建立候选，再到对应院系的研招文件逐项核对。并排比较前统一招生年份、学院、专业代码、方向和学习方式。涉及初试时记录完整科目代码和名称，标出可先学的共同内容与切换后需补的内容。涉及人数时先读表头和备注，区分拟招总数、推免、统考计划及实际录取，推算前核实口径。目标年度文件尚未发布时，在演示画面上标明所用年份，给出正式目录发布后的复查动作。

不要默认生成“保上岸、必提分、内部关系、所有双非都适合、不歧视所有本科、黑名单学校”等绝对承诺。院校层面的判断需进一步限定年份、学院、专业与证据；不能拿评论传闻代替结论。把缺乏证据的“揭黑”改成可核查的风险识别方法，同时保留用户关心的具体问题。

商业承接服从用户实际能力：

- 没有产品：优先展示过程、收集观众下一步问题或延续相关内容。
- 有真实资料或工具：确认内容、领取方式确实存在，再写领取提示。
- 有可交付的服务：把本条解决的基础问题与服务进一步解决的问题接起来，明确适用人群与服务内容；不要凭空生成商品、价格、效果或承诺。

结尾动作可省略。需要时只给一个与正文同一需求有关的下一步，不强塞“评论扣1”“私信领资料”。发布、私信与修改外部账号须另有实际授权。

## 6. 排序与输出

用以下标准内部筛选并说明推荐先做哪几条：目标人群是否清楚；问题是否具体；能否交付可执行帮助；证据能否取得；创作者是否能完成；是否符合本批目标。优先级表达编辑判断与制作准备程度，**不输出虚构的爆款概率、预测播放量或付费转化率**。

默认输出结构：

1. **研究依据与判断**：简述参考了哪些有数据的样本、各学什么、为什么适合当前创作者；附原作链接和数据观察日期。随后明确主要人群、当前任务、内容目的和关键假设。已有对话分析可简述，不重复整份报告。
2. **选题表**：编号｜标题｜具体困惑/钩子｜正文交付｜内容目的与拍法。每条交付要有差异，准备不足的题标出需补的关键材料。
3. **最适合先做的三条**：每条给出推荐理由、痛点与钩子逻辑、两个标题或开头版本及取舍、三段正文、具体示例/展示材料、事实核查项、一个可选结尾。区分可见的表层问题与推测的深层顾虑，不把心理推断写成调研结论。用户只要标题时可压缩，但内部仍完成兑现检查。
4. **迁移与测试**：说明从参考内容迁移了哪一层结构，下一轮准备比较什么表达；把观察、推断和创作建议分开写，不要每条都堆砌相同免责声明。
5. **发布前还需准备什么**：只列真正缺少且影响发布的材料。已有依据的选题与需核查的选题明确区分，避免把所有内容一律标成不可用。

若用户要求脚本，再按其长度展开具体口播和画面；不为了显得完整默认附加长营销方案。

## 7. 检查和复盘

交付前逐条确认：

- 标题的问题在正文中得到回答，钩子强度未超过证据。
- 开头不是空泛的“很多同学问”“今天给你干货”，除非有实际语境。
- 内容包含具体动作、条件、例子或判断标准。
- 没有虚构资历、案例、机构、数据、可领取材料与已存在的服务。
- 不直接搬运参考作者的整段文案或整套学校名单。
- 具体事实有当前来源，缺失事实有明确核查路径。
- 没有把抽样相关性、评论热度或收藏量解释成收入证明。
- 本批不是同一痛点的简单换词，优先题适合用户实际制作能力。
- 研究有可识别的高互动样本，自己的取舍判断、人群任务和传播技巧都实际影响了输出，而非只在开头罗列理论名词。

复盘时优先请用户提供作品链接、发布时间、时长、平台给出的播放和互动指标、留存数据（如有）、有代表性的评论以及本条目标。按同账号相似作品比较，保留观察周期。用“待验证的解释 + 下一条只改变一个主要变量的方案”指导迭代；缺少数据时做定性复盘，不输出伪精确分数。
